# Contributing to kiset

## Note

This is a small project and managed by a single developer. Please contact the developer directly before contributing:

1. GitHub Issues / Discussions
2. Twitter <https://x.com/adityab.tech>
3. Email <hello@adityab.tech>

## Development Setup

```bash
bun install
```

## Running

```bash
bun run dev              # Development mode
bun src/cli.ts           # Run CLI directly
```

## Code Style

- No comments unless necessary

## Submitting Changes

1. Fork the repository
2. Create a feature branch
3. Make your changes
4. Run type checking: `tsc --noEmit`
5. Submit a pull request with a clear description
